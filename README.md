# SSSB Routing System

You have reached the UI endpoint of the routing and navigation system for the SmallSmartSandbox (SSSB).

## Overview

The central entry point for navigating the SSSB sandbox and its components.

## Structure

| Path       | Description                                  |
|------------|----------------------------------------------|
| **`/tests/`**  | Access to `routing.json` for automated tests. |
| **`/ethics/`** | Access to the SSSB Code of Ethics for AI Systems. |

## Features

* Route Management — Centralized handling of routes.
* Navigation — Structured access to sandbox pages and components.
* Hosting — Published via GitHub Pages.

## Deployment

Endpoints live at: https://smallsmartsandbox.github.io/
