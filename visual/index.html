Small Smart Sandbox

A controlled environment for testing and studying autonomous AI behavior — how models plan, use tools, adapt, and stay within bounds.

Autonomous behavior Goal pursuit Tool use Adaptation Safety mechanisms Containment

Focus

  • Autonomous behavior — how a model plans and acts without step-by-step instructions.
  • Goal pursuit — whether and how it works toward a given objective.
  • Tool use — when it decides to read or edit files, or exchange data with a server.
  • Adaptation — how it reacts to errors, feedback, and changing conditions.
  • Safety mechanisms — which actions are permitted and how limits are enforced.
  • Containment — how well the agent stays inside the sandbox.

Status

Early development. The project is experimental and its methods and goals may evolve over time. The interactive entry point is still under active development.
